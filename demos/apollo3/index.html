Apollo 3 in JBrowse, with no server

Apollo 3 edits annotations inside JBrowse. It is usually run against a collaboration server, but it does not have to be: an assembly that names no internet account stores its edits in the browser instead. This demo is that mode, over a Tiberius gene prediction on human chr22.

Open with the prediction loaded Open with an empty annotation track

What you are looking at

Three tracks at chr22:49,987,402-50,067,759: the Tiberius prediction, GENCODE 47 for comparison, and Annotations (Human (hg38)), which Apollo adds by itself and which is the editable one. Tiberius predicts one model across this window where GENCODE annotates two genes, IL17REL and TTLL8. Splitting that model in two is an edit, which is where a browser stops and an editor starts.

The first link seeds the editable track with the prediction. The second starts it empty, and you can pull any model in by right-clicking it in the Tiberius track and choosing Create Apollo annotation.

Where the edits go

Into IndexedDB in your own browser, under Apollo-hg38. They are not uploaded anywhere, they are not shared, and clearing site data for jbrowse.org removes them. Use Download GFF3 in the Apollo menu to keep anything worth keeping.

Running it yourself

The config is config.json. The parts that matter are the plugins entry pointing at the Apollo bundle, and the absence of any internetAccounts key: that absence is what selects the local, server-free driver. The Sequence Ontology is pinned to a copy served from this directory, so the page does not fetch it from GitHub on every load.

Apollo 3 is by the Apollo team and is documented at GMOD/Apollo3. The plugin bundle here is built from its JBrowse 5 branch. The gene review workflow this demo is the editing end of is described in the gene prediction review tutorial.

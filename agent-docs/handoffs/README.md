# Handoffs index

> **Generated — don't hand-edit the table.** `pnpm autogen` rewrites it from
> each doc's `description:` frontmatter
> ([`website/scripts/generate-doc-indexes.ts`](../../website/scripts/generate-doc-indexes.ts)),
> so fix the handoff a row is wrong about, not the row. `pnpm autogen --check`
> fails CI on a stale table or a doc carrying no frontmatter.

A handoff is the live state of an **unfinished** thread — most often a review or
an audit whose findings nobody has committed to yet. It holds pointers, not
content, and it gets **deleted** when the thread lands.

**Everything a handoff finds has a permanent home somewhere else**, and a handoff
that outlives its thread is a stale copy of one:

| what it is | where it goes |
| --- | --- |
| a worked proposal, not yet started | [ideas/](../ideas/README.md), one file each |
| work someone intends to do | [TODO.md](../TODO.md) |
| a measurement, or how a subsystem works | [reference/](../reference/README.md) |
| tried and declined | a sentence at the site, with the number |
| what a session did, and which commits | git already holds it |

So a thread is closed by filing its remainder into those and removing the file.
A handoff is the fastest agent-doc to go stale, because its subject is still
moving. **The directory being empty is the normal state**, not a sign the index
is broken.

A stale handoff most often holds a **worked proposal**, which belongs in
`ideas/` where the index surfaces it. Next most often it is a **reference doc
in a handoff's clothes**: it publishes a measurement
(`generate-measurement-tables` allows one publisher per record, so the handoff
becomes that record's permanent home until it moves), or it carries a fixed
protocol someone is meant to follow again. Before filing anything, check what
the handoff duplicates: the docs it pointed at have usually absorbed its
content.

A handoff's `description:` is its row here, and what it is still waiting on is
the thing to write there — a reader picks a thread up by what is unresolved in
it.

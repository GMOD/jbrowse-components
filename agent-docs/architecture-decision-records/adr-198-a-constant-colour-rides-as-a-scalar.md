# ADR-198: A constant colour rides as a scalar

## Status

Accepted (2026-09-28). Meets the second of
[ADR-152](adr-152-wiggle-stays-off-the-column-encoder-until-two-lanes-go.md)'s
conditions and answers, for colour, the call
[wiggle-onto-bar-and-point](../ideas/waiting-on-a-call/wiggle-onto-bar-and-point.md)
waits on.

## Context

After [ADR-193](adr-193-an-adapter-answers-the-mark-pipeline-its-typed-arrays.md)
declined the identity `featureIndex`, a bar's payload over a BigWig was `x`,
`x2`, `y` and a colour lane: 16 bytes a feature against wiggle's 12. The colour
lane was `color.fill(paint)` over every instance of a layer whose colour is one
CSS colour, which is every bar a config writes without a `color`, and wiggle
holds that colour once per source. ADR-152 named the lane as the four bytes
left, and the ready idea
[wiggle-instance-records-carry-per-row-constants](../ideas/ready/wiggle-instance-records-carry-per-row-constants.md)
reached the same constant from the GPU side.

## Decision

- **`color` is `Uint32Array | number`**, on `EncodedChannels`
  (`packages/core/src/util/markEncodingTypes.ts`) and on render-core's
  `ColorChannel`. `encodeFeatures` answers the number where `unscaledColor`
  answers a constant, and `encodedChannelTransferables` lists no buffer for
  it. A categorical, threshold or ramp colour stays a lane even where every
  instance takes one colour, and so does a `jexl:` or reader colour.
- **`colorAt(channels, i)` reads either**, exported beside `featureIndexAt`,
  its twin for the other lane that is sometimes absent. The hover
  (`findMarkHit`), the text mark's own colour and the Manhattan tooltip read
  through it.
- **The instance record does not change.** `colorBits(c, count)` fills a lane
  for the pack alone, which the payload never holds; `paintColors` expands once
  for Canvas2D and keeps the lane on the payload as `constantBake`, which
  `rampBake` already does for a ramp. The shader codegen learns no scalar, for
  the reason its header gives against per-field descriptors.
- **A union, not a sibling field.** Under the union typescript7 names every
  site that indexes `color`, where a `colorConstant` beside an optional lane
  would let a tooltip swatch read `undefined` in silence. A grep found the one
  production reader the review had not listed, the MAF display's span pick;
  the typecheck then named test and bench sites alone, in 21 files, which
  narrow the lane they built.
- **Every consumer keeps a number as it is**: `facet.ts` gathers only a lane,
  the density tier emits its sidecar's colour as the number rather than
  filling a lane per bin, `drawnScales` scans only a lane, and the arc hover's
  one-instance slice and the MAF display's span pick pass a number through
  (`instanceColor`).

## Consequences

- **A bar's payload is wiggle's 12 bytes a feature over raw rows**
  (12<!--m:scalar-colour-bigwig.raw.headBytes-->, from
  16<!--m:scalar-colour-bigwig.raw.baseBytes-->), and below wiggle's at a
  summary tier, where wiggle keeps a minimum and a maximum beside each score.
  ADR-152's second condition is met.
- **The raw tier sits on ADR-152's 1.10x line, not clearly under it.** The
  table arm runs at 1.09x<!--m:scalar-colour-bigwig.raw.headVsWiggle-->
  wiggle there, against
  1.15x<!--m:scalar-colour-bigwig.raw.baseVsWiggle--> for the lane, and at
  1.00x<!--m:scalar-colour-bigwig.2048-synthetic.headVsWiggle--> at the
  synthetic tier. The gap to the lane was measured beside a memory-heavy job;
  an in-process A/B on a quieter box read the two level at 1.12x, where
  filling 441,000 colours was a tenth to half a millisecond of a 2.5 ms
  encode. What stands between the raw tier and wiggle is the encode's copy of
  `x`, `x2` and `y` and its admit pass over `y`, against wiggle's 0.8 ms pack,
  not colour.
- **Canvas2D holds the lane the payload no longer ships.** A display drawn
  through the Canvas2D fallback keeps `constantBake` beside the payload once it
  paints, as it keeps a ramp's bake; the GPU path never writes it.
- **`row` is the same question one lane over.** A multi-wiggle source is a
  layer standing in one row, and ADR-152's third condition asks for the row as
  a per-layer constant; the same union, read through a `rowAt`, answers it the
  same way, with `rowLane` already filling zeros at pack time for a layer that
  has none.

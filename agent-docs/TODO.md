**One file per item, under [todo/](todo/), and the tables below are generated
from them** by `website/scripts/generate-todo-index.ts` (`pnpm autogen`, or
`--check` in CI). Each entry carries the whole of its row in its own
frontmatter — `metadata.category` picks the table, `area` and `first_move` are
the two columns, `order` is where it sits — and the row's label is the entry's
`# ` heading. So file a new entry by writing the doc and running `pnpm autogen`;
don't edit between the markers. A row cannot go missing or point at a file that
was renamed, which is how the hand-maintained version drifted twice.

**Each table is in the order to take it**, and a short paragraph above each says
what that order is by — so the top row is a real recommendation rather than
whichever entry was filed first. Two entries in one table cannot share an
`order`, and a closed entry is welcome to leave a gap. Whether the sequence
still matches the reason above the table is editorial, and nothing checks it;
re-number when it stops.

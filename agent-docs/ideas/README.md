# Ideas index

> **Generated — don't hand-edit the table.** `pnpm autogen` rewrites it from
> each doc's `description:` frontmatter
> ([`website/scripts/generate-doc-indexes.ts`](../../website/scripts/generate-doc-indexes.ts)),
> so fix the entry a row is wrong about, not the row. `pnpm autogen --check`
> fails CI on a stale table or a doc carrying no frontmatter.

Exploratory concepts and folded proposals — not committed work. Concrete action
items live in [TODO.md](../TODO.md); the split between them is commitment, not
size.

**Skim this table for your subsystem before proposing something.** A parked
proposal here often already contains the reasoning that kills the obvious
version of the idea, which is why re-proposing without reading it wastes a
session. A fair number were written precisely so the next session doesn't
re-derive them.

One file per proposal, so a heavy one can be taken off the shelf and worked
without reading its neighbours. A proposal's `description:` is both its row here
and what a reader sees when they grep the directory, so write it as the hook
someone picks the idea up by, not as a summary.

**The subfolder says what the proposal is waiting on**, so `ls` answers the
question this index answers, for the reader who never opens it:

| Folder | What is holding it up |
| --- | --- |
| `ready/` | Nothing but the work. The design is settled in the doc. |
| `waiting-on-a-call/` | A decision. Most are small once it is made — that is why this folder is the largest. |
| `waiting-on-a-number/` | A measurement, named in the doc, that decides whether to build at all. |
| `waiting-on-someone-else/` | Upstream, a client, data, or a CI runner this repo does not own. |
| `collections/` | Several proposals in one file. Triage inside it, not as a unit. |

Moving a doc between folders is how its status changes, and the folder is the
only place that status is written — nothing duplicates it in frontmatter, so
the two cannot disagree. A doc left loose at the top level fails `pnpm autogen`.

These were one file (`OTHER_IDEAS.md`) until 2026-08-13, and other docs and a
couple of source comments cite entries **by path** now rather than by section
title, so moving one between folders is a grep — the same one renaming it
always was. `website/scripts/check-doc-imports.ts` fails on every reference the
move left behind, which is what makes it safe to do.

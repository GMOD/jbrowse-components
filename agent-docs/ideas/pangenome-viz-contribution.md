# A contribution to `pangenome/jbrowse-visualization`

Their guide stops at one MAF view via `wgatools` + `mafchunk` + `maf2bed` plus a
plugin-store install. `@jbrowse/plugin-maf` is in core now, and the graph,
synteny, variants and depth projections are all possible off the same pggb
output — so the guide is describing a harder version of something that got
easier. A draft exists at
`~/scratch/jbrowse-pangenome/jbrowse-visualization-contribution.md` and carries
its own check-before-sending list. Nothing has been sent, and sending it is a
decision about representing the project rather than an implementation task.

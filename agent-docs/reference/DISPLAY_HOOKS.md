# Display hooks and their defaults

[ARCHITECTURE.md](../ARCHITECTURE.md#display-stacks) says what a display composed. The
table says which displays override which hook; every default keeps working and does less.
The generator asserts each hook is still declared by the file owning its default, so a
rename cannot leave consumers reading `undefined` as a boolean.

A display that extends another plugin's whole model (`LGVSyntenyDisplay` over
`LinearAlignmentsDisplay`, GC content over `LinearWiggleDisplay`) stands in the table as its
composer, by design. Don't tag inheritors. The hooks come with the parent and may not suit
the subclass.

Render path is a separate axis: the backend factory picks GPU or Canvas2D per frame
([GPU_BACKENDS.md](GPU_BACKENDS.md#renderingbackend-interfaces-per-plugin)).

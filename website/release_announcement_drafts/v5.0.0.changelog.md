## Changes since v4.3.0

The release notes above cover the highlights. This is the full list of features
added since v4.3.0, grouped by area. Performance work is summarized in the
notes, and bug fixes are not listed individually — the work landed on main
directly rather than through pull requests, so
[the commit range](https://github.com/GMOD/jbrowse-components/compare/v4.3.0...v5.0.0)
is the complete record.

![The ship of Theseus: every surviving line of source in the repository, colored by the month it was written](https://jbrowse.org/jb2/img/blog/v5.0.0/code_age.png)

_777,000 of the 858,000 lines standing today were written after February 2026;
all of 2018-2025 contributes 82,000. Hand-written source only — tests included,
generated and vendored code excluded._

![What the lines are: every hand-written source line in the repository, weekly, split into app source, tests, docs tooling and scripts](https://jbrowse.org/jb2/img/blog/v5.0.0/code_composition.png)

_Snapshots follow the development line — the rewrite branch from February, then
main once it merged on 15 July — so the work sits where it was written rather
than where it landed._

![The same six months day by day, once with test code and once without](https://jbrowse.org/jb2/img/blog/v5.0.0/code_growth_zoom.png)

_Both panels carry one scale, so the gap between them is the test code._

![The same six months as lines standing and as lines written: added above the axis, deleted below](https://jbrowse.org/jb2/img/blog/v5.0.0/code_churn.png)

_A rewrite deletes about as much as it writes, so the flat stretch above is not
idle time — it is the same files being replaced._

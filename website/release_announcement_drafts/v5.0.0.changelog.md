## Changes since v4.3.0

The release notes above cover the highlights. This is the list of features added
since v4.3.0, grouped by area, with a feature that landed over several commits
written once as what it ended up being. Performance work is summarized in the
notes; bug fixes, internal refactors and build tooling are not listed
individually. The work landed on main directly rather than through pull
requests, so
[the commit range](https://github.com/GMOD/jbrowse-components/compare/v4.3.0...v5.0.0)
is the complete record.

![The ship of Theseus: every surviving line of source in the repository, colored by the month it was written](https://jbrowse.org/jb2/img/blog/v5.0.0/code_age.png)

_778,685 of the 860,363 lines standing today were written after February 2026;
everything from 2018 through January 2026 contributes 81,678. Hand-written
source only — tests included, generated and vendored code excluded._

![What the lines are: every hand-written source line in the repository, weekly, split into app source, tests, docs tooling and scripts](https://jbrowse.org/jb2/img/blog/v5.0.0/code_composition.png)

_Snapshots follow the development line — the rewrite branch from February, then
main once it merged on 15 July — so the work sits where it was written rather
than where it landed._

### Alignments

#### Reads

- restore per-base quality color-by
- reach mate-chromosome coloring, and stop greying out Track sizing
- an option to disable low-frequency mismatch filtering, which draws the
  survivors at full alpha
- "Fade mismatches by base quality" (mismatchAlpha) is back, as a promotable
  setting in the top-level Show menu
- draw indels for any feature carrying a CIGAR
- copy read name or sequence from the pileup context menu
- one menu for read height and track sizing, with "Fit to display height" as a
  radio mode beside the presets, a 1px gap between reads once they are over 3px
  tall, and the mode persisted through a promotable heightMode slot
- promotable session defaults for colorBy, view-as-pairs and read-connections,
  each naming the scheme it would pin

#### Filtering, sorting and grouping

- unify the read filters under "Filter by...", and gate the pileup-only menus
- singleton / proper-pair filters in pileup mode, and a "Show only split
  alignments" filter
- "Sort by" on the read right-click menu, Tag among its options, and the center
  line revealed when a center-line sort is applied
- make groupBy a config slot, for declarative pre-grouping
- per-group pileup height drag, grouped pileups fit to the viewport, and a tall
  pileup scrolls on the wheel
- one insert-size color scale shared across grouped sections
- one row per group via collapseGroupRows

#### Arcs and connectors

- filter junction arcs by minimum read support
- dash split-read connector arcs to disambiguate them from RR pairs, and give
  split-read inversion and deletion distinct colors across fill, connector and
  arc alike
- clarify the linked-read connection curves with a legend and a hover
- one insert-size classifier shared between the read filter and the arcs
- the read legend reflects what is actually rendered, and draws each key row as
  the mark it names
- coalesce identical arcs, and draw each at its read-support width on all three
  backends
- one read outline and one arc geometry across WebGL, Canvas2D and SVG
- hit-test the arc band against the curve it draws
- an arc hover names its junction — location, distance, supporting reads, insert
  size, and the color bucket's own legend wording

  arc the tooltip is describing

  stops reading as an arc's foot

  breakend feet on the side the junction keeps

  color bucket, and an overlap stops being painted as one arm

  the heavy junctions biased to the upper band
- color sashimi arcs with the read-alignment strand colors
- a showSashimiLabels config slot and menu toggle

#### Coverage

- coverage gains log scale, autoscale type and min/max score bounds, off the
  same config slots and domain logic wiggle uses

  an insertion summary, a stable order, and both orientation and insert-size

#### Modifications and methylation

- simpler modification color-by labels, and a corrected fill-view legend

#### Consensus sequence

- note what consensus variants are not

#### Structural variants

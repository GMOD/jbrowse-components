GPU-accelerated feature display with gene-specific UI on top of the shared
canvas base display (`LinearFeatureBaseDisplay`).

## Example usage

A `FeatureTrack` with compact features. `displayMode` is `normal`,
`compact`, `superCompact` or `collapsed` (one row):

```js
{
  type: 'FeatureTrack',
  trackId: 'genes',
  name: 'Genes',
  assemblyNames: ['hg38'],
  adapter: {
    type: 'Gff3TabixAdapter',
    uri: 'https://example.com/genes.gff3.gz',
  },
  displays: [
    {
      type: 'LinearBasicDisplay',
      displayId: 'genes-LinearBasicDisplay',
      height: 200,
      displayMode: 'compact',
    },
  ],
}
```

The configuration slots for this model are documented on its [config schema page](../../config/linearbasicdisplay).

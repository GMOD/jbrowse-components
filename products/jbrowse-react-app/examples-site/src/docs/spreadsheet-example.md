`SpreadsheetView` opens a tabular file — a VCF here — as a sortable, filterable
spreadsheet. Note that **`uri` goes on `init`**, not in a track config.

Fields: [SpreadsheetView](https://jbrowse.org/jb2/docs/models/spreadsheetview/).
To pair a spreadsheet with a circular view that highlights breakends, see the
[SV inspector](#sv-inspector-example).

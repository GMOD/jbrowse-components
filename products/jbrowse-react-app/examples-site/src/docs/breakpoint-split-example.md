`BreakpointSplitView` stacks two or more linear genome views and draws curves
between the breakpoints of split and translocated reads. `init.views` is one
`{ loc, assembly, tracks }` per stacked panel.

Fields:
[BreakpointSplitView](https://jbrowse.org/jb2/docs/models/breakpointsplitview/).
For this on real data, see the
[cancer SV tutorial](https://jbrowse.org/jb2/docs/tutorials/sv_visualization_cgiab/).

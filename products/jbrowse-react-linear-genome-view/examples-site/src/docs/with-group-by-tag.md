`color` and `facet` are the grammar of graphics' colour scale and facet over one
field, ggplot2's `aes(colour = HP)` and `facet_grid(rows = vars(HP))`. Each
takes `{ field, domain }`, and a `domain` lists the values that come first, in
order.
[Grouping and lane order](https://jbrowse.org/jb2/docs/config_guides/grouping_and_ordering/)
covers every display that takes a facet.

`facet` groups the reads on their HP tag and `baseColor` paints each CpG from
the MM and ML tags. `unmodified: 'all'` colors the CpGs the basecaller left
implicit, so an unmethylated read is blue and not blank. The
[methylation tutorial](https://jbrowse.org/jb2/docs/tutorials/methylation/)
builds this view from the menus.

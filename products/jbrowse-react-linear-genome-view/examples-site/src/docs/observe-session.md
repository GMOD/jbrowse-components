An `observer` re-renders when what it reads changes: `session.selection`, or the
view's regions. Key a fetch off `coarseDynamicBlocks`, the throttled twin of
`dynamicBlocks`, or a drag fires one per frame; the generation counter keeps an
older fetch from landing last. To replace the drawer with your own panel, see
[Feature details on click](https://jbrowse.org/storybook/byo/feature-details/).

Browse the [Pan-UK Biobank](https://pan.ukbb.broadinstitute.org/) GWAS across
its full phenotype catalog. The search box filters a trimmed copy of the
official manifest (generated by `scripts/gen-panukb-manifest.mjs`); picking a
phenotype loads that trait's tabix-indexed summary statistics straight from the
Pan-UKBB public S3 bucket and renders them as a Manhattan plot. The
**Population** dropdown switches which column drives the plot — the
cross-ancestry meta-analysis or any single ancestry the trait was actually run
in.

Each phenotype file is one `GWASTrack` with a `GWASAdapter`. The Pan-UKBB flat
files expose `neglog10_pval_*` columns that are already −log₁₀(p), so the
adapter reads the selected population column directly as the Manhattan score
(`scoreTransform: 'none'`, the default). For files whose p-value column is not
pre-transformed, `scoreTransform` takes `negLog10` for a raw p-value or
`negLog10FromLn` for a natural-log one (the convention Pan-UKBB uses in its
Hail-format release). The transform is applied natively per feature, so it stays
fast across a genome-wide view.

Featured phenotypes open zoomed to a known lead locus; any other opens on
chromosome 1. For LD-colored Manhattan plots, see
[LocusZoom-style LD](../locus-zoom-ld/).

[GWAS track guide](https://jbrowse.org/jb2/docs/config_guides/gwas_track/),
[GWASTrack](https://jbrowse.org/jb2/docs/config/gwastrack/),

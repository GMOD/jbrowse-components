A ring is a linear display's strip wrapped round the circle, ggplot2's
`coord_polar()`. Both rings read one bigWig: `mark: 'rect'` shades each bin, and
the `marks` ring declares a `bar` whose height and color read `score`. The
[mark display guide](https://jbrowse.org/jb2/docs/config_guides/mark_display/)
has every channel, scale and transform.
